# MeetHub 画面設計たたき台(画面一覧・遷移図)

[要件定義書](./requirements.md)の機能一覧に対応する画面一覧と遷移図。詳細設計に入る前のたたき台であり、レイアウトの詳細(コンポーネント構成・スタイル等)は実装フェーズで別途検討する。

## 1. 画面一覧

| 画面名 | 目的 | 主な要素 |
|---|---|---|
| ログイン画面 | 既存ユーザーの認証 | メールアドレス/パスワード入力、ログインボタン、新規登録画面へのリンク |
| ユーザー登録画面 | 新規アカウント作成 | ユーザー名・メールアドレス・パスワード入力、登録ボタン |
| イベント一覧画面(ホーム) | イベント閲覧の起点 | 開催日時が近い順の一覧、全体/フォロー中主催者タブ、イベント作成の入口 |
| イベント作成 | 新規イベントの作成 | タイトル・開催日時・場所・説明・画像・定員の入力、作成ボタン(モーダル想定) |
| イベント詳細画面 | 1イベントの詳細と参加申込み・コメント | タイトル・日時・場所・説明・画像、興味ありボタン、現在の参加人数/定員、参加申込み・取消しボタン、コメント一覧・入力欄、(主催者本人のみ)編集・削除ボタン・参加者一覧。編集はイベント作成と共通のモーダルで行う |
| プロフィール画面 | ユーザーの主催イベント一覧とプロフィール情報 | アイコン・表示名・自己紹介、フォロー/フォロー解除ボタン(他人の場合)、そのユーザーが主催するイベント一覧 |
| プロフィール編集画面 | 自分のプロフィール編集 | 表示名・自己紹介・アイコン変更 |
| フォロー一覧 / フォロワー一覧画面 | 特定ユーザーのフォロー・フォロワー関係を閲覧 | ユーザーリスト(各行からプロフィール画面へ遷移) |
| マイ参加予定イベント一覧画面 | 自分が参加申込みしたイベントの確認 | 開催日時が近い順の申込み済みイベント一覧、各行から取消し操作 |

## 2. 画面遷移図

```mermaid
flowchart TD
    Login[ログイン画面] -->|ログイン成功| EventList[イベント一覧画面]
    Login -->|新規登録へ| Signup[ユーザー登録画面]
    Signup -->|登録成功| EventList

    EventList -->|イベント作成ボタン| EventCreate[イベント作成]
    EventCreate -->|作成完了| EventList
    EventList -->|イベントクリック| EventDetail[イベント詳細画面]
    EventList -->|主催者名クリック| Profile[プロフィール画面]
    EventList -->|マイ参加予定へ| MyJoins[マイ参加予定イベント一覧画面]

    EventDetail -->|主催者が編集(モーダル)| EventDetail
    EventDetail -->|削除| EventList
    EventDetail -->|参加申込み/取消し| EventDetail
    EventDetail -->|主催者名クリック| Profile

    MyJoins -->|イベントクリック| EventDetail

    Profile -->|自分のプロフィール編集| ProfileEdit[プロフィール編集画面]
    ProfileEdit -->|保存| Profile
    Profile -->|フォロー一覧/フォロワー一覧| FollowList[フォロー一覧/フォロワー一覧画面]
    FollowList -->|ユーザークリック| Profile
    Profile -->|主催イベントクリック| EventDetail
```

## 3. 補足

- イベント作成はイベント一覧画面上のモーダル表示を想定しているが、実装フェーズで専用画面に分けるかは再検討可能。
- 参加者一覧は主催者本人がイベント詳細画面から閲覧する想定で、専用画面は設けない(実装フェーズで再検討可能)。
- ナビゲーション(ヘッダー/サイドバー等)の具体構成は本ドキュメントでは定義せず、実装フェーズのUI設計で決定する。
